# Endfield-Bridge

Endfield-Bridge 是 ENDF2Blend 的 Blender 前端插件。它通过 Sora-Core 浏览《明日方舟：终末地》资源，并将模型、材质和动画导入 Blender；导入后可在插件面板中调整姿势、表情和装备。

插件需要单独配置 Sora-Core 可执行文件，以及对应的游戏目录和 `.sredb` 数据库。安装说明见 [Releases](https://github.com/SaigyoujiYusora/Endfield-Bridge/releases)。
